FilmCountour — приложение для поиска и просмотра торрент-раздач на компьютере.
Встроенный плеер позволяет начать просмотр до завершения загрузки. Android-клиент
подключается к компьютеру по локальной сети и воспроизводит видео с него.

Этот репозиторий содержит описание приложения и готовые сборки. Исходный код
приложения здесь не публикуется. Для скачивания регистрация на GitHub не нужна.

## Возможности

- Поиск фильмов и сериалов на RuTracker, Rutor и NNM-Club.
- Просмотр видео во время загрузки раздачи.
- Выбор эпизодов, отдельных файлов и целых папок.
- Выбор готовых внешних аудиодорожек.
- Встроенный плеер и запуск видео в установленном mpv, VLC или другом плеере.
- Просмотр видео с компьютера на Android по локальной сети.

## Установка

**Windows:** скачайте и запустите установщик `.exe`.

**Linux:** скачайте AppImage, разрешите выполнение и запустите его:

```sh
chmod +x FilmCountour-1.0.63-x86_64.AppImage
./FilmCountour-1.0.63-x86_64.AppImage
```

AppImage собран на Ubuntu 24.04; запуск проверен на Arch Linux/KDE. Проверка рабочего стола Ubuntu для этой версии не проводилась.

**Android:** установите APK, включите доступ с телефона в настройках FilmCountour
на ПК и подключитесь из приложения в той же локальной сети. Файлы раздач остаются
на компьютере; FilmCountour на ПК должен быть запущен.
